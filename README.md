# Sistema de Parqueadero Inteligente

Proyecto desarrollado en C++, Python y SWIG para la gestión de un parqueadero mediante comunicación cliente-servidor.

## Funciones

- Generación automática de placas
- Comunicación mediante sockets TCP
- Registro de entradas y salidas
- Reutilización de celdas
- Librerías dinámicas con SWIG
- Interfaz gráfica en Python
- Visualización en tiempo real

## Estructura

Cliente/
Servidor/
Libreria/
Visualizador/

## Ejecución

Servidor:

cd Servidor

./servidor

Cliente:

cd Cliente

./cliente

Visualizador:

cd Visualizador

python3 visualizador.py
